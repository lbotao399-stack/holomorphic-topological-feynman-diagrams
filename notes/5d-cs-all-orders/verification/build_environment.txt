Local PDF build environment
===========================

The PDF was compiled entirely with installed TeX files. No network compiler,
remote build service, or Tectonic invocation was used for this build. Shell
escape was explicitly disabled for every manuscript compilation.

Engine:
  pdfTeX 3.141592653-2.6-1.40.26 (TeX Live 2025/dev/Debian)
  LaTeX2e 2024-11-01 patch level 2
  L3 programming layer 2025-01-18

The installed distribution lacked the generated pdflatex format and default
font-map file. Both were assembled in a scratch directory from installed
sources, without changing system configuration or mathematical content.

Source working directory:
  /workspace/scratch/1ee09186baec/holomorphic-topological-feynman-diagrams/notes/5d-cs-all-orders

Build directory:
  /workspace/scratch/1ee09186baec/tex-build

1. Create local directories:

mkdir -p /workspace/scratch/1ee09186baec/tex-build/formats /workspace/scratch/1ee09186baec/tex-build/pdf /workspace/scratch/1ee09186baec/tex-build/render

2. From tex-build/formats, generate the format using the installed sources:

env TEXMF='{/usr/share/texlive/texmf-dist,/usr/share/texmf,/etc/texmf,/var/lib/texmf}' pdftex -ini -etex -jobname=pdflatex -progname=pdflatex -interaction=nonstopmode -halt-on-error pdflatex.ini

3. Assemble tex-build/pdftex.map from the following installed files:

  /usr/share/texmf/fonts/map/dvips/lm/lm.map
  /usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts/cm.map
  /usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts/cmextra.map
  /usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts/symbols.map
  /usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts/euler.map
  /usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts/latxfont.map

The exact assembly code was:

from pathlib import Path
sources = [
    Path('/usr/share/texmf/fonts/map/dvips/lm/lm.map'),
    *[Path('/usr/share/texlive/texmf-dist/fonts/map/dvips/amsfonts') / name
      for name in ('cm.map', 'cmextra.map', 'symbols.map', 'euler.map', 'latxfont.map')],
]
seen = set()
lines = []
for source in sources:
    for line in source.read_text().splitlines():
        stripped = line.strip()
        if not stripped or stripped.startswith('%'):
            continue
        name = stripped.split()[0]
        if name not in seen:
            lines.append(line)
            seen.add(name)
Path('/workspace/scratch/1ee09186baec/tex-build/pdftex.map').write_text(
    '\n'.join(lines) + '\n'
)

This produced 752 font entries.

4. From the source working directory, compile with the local format and map:

env TEXMF='{/usr/share/texlive/texmf-dist,/usr/share/texmf,/etc/texmf,/var/lib/texmf}' TEXFORMATS=/workspace/scratch/1ee09186baec/tex-build/formats TEXFONTMAPS=/workspace/scratch/1ee09186baec/tex-build: pdflatex -no-shell-escape -interaction=nonstopmode -halt-on-error -file-line-error -output-directory=/workspace/scratch/1ee09186baec/tex-build/pdf paper.tex

The manuscript uses an inline bibliography. No BibTeX or Biber run is needed.
The command was repeated after layout changes until all references were stable.

5. Validation:

  pdfinfo /workspace/scratch/1ee09186baec/tex-build/pdf/paper.pdf
  pdffonts /workspace/scratch/1ee09186baec/tex-build/pdf/paper.pdf

All pages were rendered with PyMuPDF for visual inspection. Tables, the cyclic
cohomology argument, the corrected contraction display, and bibliography were
also inspected at 1.4 times the native PDF point resolution.

The final engine transcript is retained as latex-build.log in this directory.
The only expected warning is that the epstopdf package cannot execute external
commands because shell escape is disabled; the manuscript contains no EPS
figures and no such conversion is needed.
