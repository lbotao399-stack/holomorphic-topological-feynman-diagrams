Supplement manifest for flagship.tex (Appendix A, "Computational certificates").
Each line: supplement path  <-  project path (P = holomorphic-twist-program/).
The supplement folder is not assembled; this file lists the scripts cited in Appendix A and the folders they are taken from.

P/explore/twoloop-universal/verify, P/deepen/normalization/verify, P/deepen/deform/code, P/deepen/simple-all/code,
P/deepen/simple-g/code); these have to be rewritten to the supplement layout.  Helper modules in the same folders

sla.py, jets.py, cohom.py, common.py, ce_eval.py, lie_eval.py, sp_coords.py, v_lie_ce_defs.py, vk.py) and data
folders (deepen/o3/code/data, deepen/o3/verify/data) belong with them.
