b1  Prop. 1.2.1: M-theory in the twisted Omega-background on TN_k x R^3 x C^2 is equivalent to
    non-commutative 5d CS on R x C^2 with gauge group GL(k+1, C).
    Action (Sec. 1.2, unnumbered):
      S(A) = (1/2delta) int Tr(A dA) dz1dz2 + (1/3delta) int Tr A^3 dz1dz2
           + int Tr sum_{n>=1} e^n/(3 delta 2^n n!) eps^{i1j1}..eps^{injn}
                 A d_{z_i1}..d_{z_in} A ^ d_{z_j1}..d_{z_jn} A  dz1dz2,
      i.e. (1/2delta) int Tr A dA dz1dz2 + (1/3delta) int A *_e A *_e A dz1dz2 with Moyal *_e.
      The n = 1 term is (e/(6delta)) eps^{ij} int Tr A d_{z_i}A ^ d_{z_j}A dz1dz2.
    Sec. 5: BV form, fields A_c (x) gl_N[1], S(alpha) = 1/2 int alpha *_e d alpha + 1/3 int alpha *_e alpha *_e alpha.

b2  Sec. 1.3, Theorem (unnumbered): the theory exists at the quantum level perturbatively in
    the regime |delta| << |e|; counterterms are unique up to redefinitions of e and delta.

b3  Sec. 9, introduction: delta is the loop-counting parameter. Negative powers of e are
    admitted in order to cancel potential higher-loop anomalies.
    Base ring: { sum_{i>=0} delta^i f_i(e) : f_i in C((e)), f_0 in C[[e]] }.

b4  Thm 9.0.2. Hypotheses: X a conical complex symplectic surface, R x X, gauge algebra gl_N
    "uniformly in N" (as in [CL15] = 1505.06703), C^x-compatible, negative powers of e only
    together with positive powers of delta.
    Conclusion: no obstructions. At each order dim H^2(X) + 1 deformations:
      S -> S + delta^k e^{-k} (1/2 int alpha d alpha + 1/3 int alpha *_e alpha *_e alpha),
      S -> S + delta^k e^{-k} int alpha *_e alpha *_{e,w} alpha,   w in H^2(X).

b5  Thm 9.0.3. Hypotheses: R x C^2, uniformly in N, C^x-compatible, sl(2)-invariant,
    holomorphically translation invariant, powers e^{-r} delta^n with r <= n.
    Conclusion: no obstructions; 2 deformations per order,
      delta^k e^{-k} (1/2 int alpha d alpha + 1/3 int alpha *_e alpha *_e alpha),
      delta^k e^{-k} e d/de int alpha *_e alpha *_e alpha,
    both absorbed by e -> e(1 + lambda_1 delta^n e^{-n}), delta -> delta(1 + lambda_2 delta^n e^{-n}).

b6  Sec. 9.1 (argument, not a proof). Local operators = C^*(gl_N[[z1,z2]]) with [z1,z2] = e;
    the BRST operator is identified with the CE differential; one restricts to GL(N)-invariants.
    Uniformly in N, Loday-Quillen and Tsygan identify single-trace operators with the dual of
    the cyclic homology of C[[z1,z2]]. For e = 0 these cyclic homology groups are
    infinite-dimensional; for e != 0 they collapse, and cohomology is freely generated in
    ghost numbers 3, 5, 7, ..., represented mod e by Tr psi^{2n+1} d_{z1}psi d_{z2}psi.
    Descent: for e != 0 the translations d_{z_i} are implemented by gauge symmetries and act
    trivially on local operators. Classes in H^2(X), H^0(X) give deformations; classes in
    H^3(X), H^1(X) give potential anomalies.

      e = 0: obstruction-deformation complex at k loops
             omega_{R x X} (x)_{D} O(pi^* J Omega^{-*}_hol[t^{-1}][1]) [N] [-6(k-1)];
             its cohomology is not computed.
      e inverted: cyclic homology of J O_X((e)) ~ C^infty_X[t^{-1}]((e))[3]
             (differential t d + e L_pi, L_pi-cohomology of J Omega^*_hol trivial);
             complex ~ Omega^*(R x X) (x) (C[eta_3, eta_5, ...]/C)[N]((e))[5];
             degree 1 = eta_5 H^1(X) + eta_3 H^3(X).
      R x C^2: C[eta_3,eta_5,...]/C (x) C[N] (x) C((e)) (x) C[dz1,dz2][5]; no sl_2-invariants
             in degrees -1 and 1; degree 0 = eta_5 C[N] + eta_3 dz1dz2 C[N].

b8  Answers to (b).
      Commutative theory: no theorem. The e = 0 complex (b7) is written down but its cohomology
      is not computed. A text search for "two-loop" and "two loop" finds nothing, so no
      two-loop obstruction of the commutative theory is mentioned or computed.
      Non-commutative theory: no obstruction (Thms 9.0.2, 9.0.3), for gl_N uniformly in N only
      (Prop. 1.2.1 uses GL(k+1)). Finite N and other algebras are not treated.
      The noncommutativity parameter enters anomaly cancellation in three places:
      (b3) negative powers of e are needed to cancel potential higher-loop anomalies;
      (b4)-(b5) the k-loop counterterms carry delta^k e^{-k};
      (b2) the theory exists in the regime |delta| << |e|.
      The paper has no statement about an order-hbar deformation cancelling an hbar^2 obstruction.
    Related statements.
      Gaiotto-Oh 1907.06495 Sec. 2.4, below (2.4): for epsilon_2 != 0, rescaling the holomorphic
      coordinates sets the noncommutativity to 1 and the coupling to hbar^{-1} = epsilon_2/epsilon_1;
      systematic renormalizability is attributed to [14] = 1610.04144. Sec. 2.5: the description
      is perturbative in epsilon_1/epsilon_2.
      GRW 2107.06734: Thm 5.1 is one loop only; the text after it says nothing is claimed about
      higher-loop obstructions. Prop. 6.4: 5d CS on R x C^2 has a finite one-loop quantization.
      Gauge: Def. 3.2, Q^GF = d*_dR (x) id + 2 id (x) dbar* (x) id. Sec. 6.2.2 compares with the
      non-commutative theory of [Cosa] = 1610.04144.

    g[[z1,z2]] restricted to sum p = 0, ghost number 1 <-> CE degree 4).

          Since S_k acts trivially on P and char = 0, this equals the sign-twisted
          S_k-invariants of C[p_1..p_k]/(P) (x) (g^*)^{(x)k}, i.e. alternating cochains on the
          hyperplane sum_j p_j = 0. This is the c5 space. The CE differential preserves total
          momentum, so the quotient is a complex.
