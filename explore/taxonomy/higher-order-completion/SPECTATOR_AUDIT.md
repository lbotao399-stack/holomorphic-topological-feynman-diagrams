# Original input colors in composed operators

## Confirmed defect and exact regression

The inherited `qn-holomorphic/fmode.py::colour_values` adds an original
input color vector only if its color index has already been introduced by
one of the two operator tensors. It introduces the final-slot indices
afterward. Thus a letter untouched by both operators has a functional
color factor but lacks its original input color vector. Its correct
contraction is the scalar product of the two colors; the inherited code
instead sums the functional vector alone.

`audit_spectators.py` records a real, nonzero history in the composition
`Q0|G2.3u`, with the matter letter untouched. It retains the complete old
and new color tensors. Replacing that original matter color by zero
leaves the inherited tensor unchanged and nonzero; the corrected tensor
vanishes. Doubling the original color doubles the corrected tensor.
A complete history without an original spectator agrees between the two
evaluators. These checks are in `spectator_audit.json`.

An actual stored calculation also changes. With exactly the old
six-dimensional inputs (`fund*1`, seed 62, ten functionals, the two jets
in `b4-round2/o2_6d10/E_f1_gvgvuJ.json`), the inherited values of
`Q0|G2.3u` were

```text
[0,4507568,2145742330,0,710826549,2147480002,2751280,0,0,0].
```

The corrected values modulo 2147483647 are

```text
[0,1100528,2145088762,0,720506549,1718132426,2143493135,0,0,0].
```

The replay is `legacy_6d_spectator_recheck.json`; it uses exact integer
color contractions and the unchanged modular kernel. This is an exact
finite-field comparison, not a rational reconstruction.

## Scope of the inherited evidence

| Existing calculation | Consequence of this defect |
|---|---|
| Six-dimensional `(1,0)`, `gv,gv,u` to `g,g,g,g,u`, including the round-two rank-three system | An untouched `u` can occur. The recorded declared-functional values require replacement. A full rational replacement is computed in this directory. |
| Six-dimensional `(1,0)`, `gv,gv,gv` to `g,g,g,u,u` | No original type occurs in the final types, so a contributing history has no original spectator. This defect does not alter it. |
| Eight-dimensional order three, four `g^v` inputs to eight `g` and one `g^v` | The reverse composition `G3|Q0` can leave one original `g^v`; the mixed lower-order compositions also require audit. `Q0|G3` consumes all four original letters and is unaffected. The recorded rank-two/sign scan cannot serve as the declared complete functional evaluation until corrected. |
| Eight-dimensional order two, three `g^v` inputs to six `g` and one `g^v` | Original spectators are possible in the reverse and mixed compositions. The corresponding functional evidence requires corrected replay. |
| Main six-dimensional `(1,1)` order-four rank-15 calculation, `b^5` to `c^5 g1 g2` | No original `b` can occur in a contributing final word. The same omission exists in `physics/6d-nilpotency/comp.py`, but this particular rank-15 calculation is unaffected by it. |
| Six-dimensional `(1,1)` control `g1 g2 b^3` to `c^7` | The input and final types are disjoint; this defect does not alter the control. |
| Auxiliary six-dimensional `(1,1)` comparison `b^4 c` to `c^7` | An original `c` spectator is possible. This auxiliary evidence requires qualification or replay. |
| Exact graph kernels, source/current densities, analytic flavor-trace anomaly arguments, and the separate three-dimensional `ht3d` engine | They do not use this missing color contraction. No conclusion about them is changed by this defect. |

This table identifies which computations the defect can affect. It does
not assert that every reported rank or graph weight changes after
correction. In particular, agreement of the old sign pattern with a new
calculation would not make the old functional values correct.

## Additive corrected evaluator

`exact_colour.py` introduces every final-slot color index before adding
**all** original color vectors. Every contraction is carried out with
Python integers. `b4_modular_probe.py` applies this correction to the
existing pooled driver without editing any inherited file. For example,
the recorded ten-functional comparison is regenerated by

```bash
python3 explore/taxonomy/higher-order-completion/b4_modular_probe.py \
  6d10 sl2 'fund*1' 2 gv,gv,u g,g,g,g,u 10 62 \
  --flav 1 --nmom 4 --jets '0:0;2:1' --unicyclic \
  --only 'Q0|G2.3u' --save /tmp/legacy_6d_spectator_recheck.json
```

The new `unicyclic_weights.py` additionally replaces modular integration
by exact rational polynomial antiderivatives on the complete simplex
domains. All original operator colors, functional colors, jets, momenta,
graph edges, output slots and histories remain explicit. Its finite
functional system determines weights only through the recorded full-rank
equations; it is not a claim of universal all-order nilpotency.

## Completed corrected eight-dimensional replay

The affected eight-dimensional functional calculations have now been
replayed with every original input color present. The kernels in this
audit are evaluated modulo 2147483647; the color contractions are over
the integers. No rational nilpotency conclusion is inferred from a zero
finite-field residual.

At order two, both complete six-functional families (seeds 11 and 12,
color-pool sizes three and five) retain all seven compositions. The
combined twelve-row system has rank three and augmented rank three.
The weights \((-1/2,-1,-1/6)\) give twelve zero residuals.

At order three, all **eighteen potentially affected compositions** were
freshly recomputed at the original three functionals: twelve reverse
`G3|Q0` compositions and six mixed lower-order compositions. Each complete
composition agrees with its historical value. The twelve `Q0|G3`
compositions consume all four original inputs and are unaffected by this
specific omission; their existing values remain declared inputs to the
thirty-composition sum. The resulting system has rank two and augmented
rank two. Exactly one of all 4,096 sign assignments survives: all twelve
signs are minus. **The twelve unrestricted weights are not uniquely
determined by a rank-two system.**

`safe_integer_contraction.py` accelerates the exact colors without a
floating contraction. Before every tensor step, the product of maximum
absolute operand entries and all summed-index dimensions bounds every
partial sum. Machine integers are used only below \(2^{62}\), otherwise
Python integers perform the step. Every completed batch checks full
nonzero 262,144-entry color tensors with and without original spectators
against the Python-integer evaluator. An independent 72-case audit also
exercises signed large integers, repeated indices, empty sums, zeros,
multioperand contractions and the overflow fallback.

The initial long batches were deliberately stopped after saving complete
composition checkpoints, then continued in independent batches. Their
partial logs are retained; no partial composition enters the verifier.
`verify_corrected_8d.py` requires exactly all eighteen corrected
compositions, checks all twelve second-order residuals, and repeats the
complete third-order sign scan. The output and dependency hashes are in
`corrected_8d_verification.json`.

```bash
python3 explore/taxonomy/higher-order-completion/verify_corrected_8d.py
python3 explore/taxonomy/higher-order-completion/verify_bounded_colour.py
```

To regenerate any full third-order composition, use its name from the
certificate; for example:

```bash
python3 explore/taxonomy/higher-order-completion/b4_bounded_integer_probe.py \
  8d so5 - 3 'g^v,g^v,g^v,g^v' 'g,g,g,g,g,g,g,g,g^v' 13 41 \
  --R 4 --nmom 4 --fsub 0:3 --only 'G1.1|G2.3' \
  --save /tmp/corrected_8d_G1_G23.json
```

The inherited scripts remain unchanged as records of the earlier
calculations. Use the corrected drivers here for composed-color
calculations involving original spectators. The six-dimensional
auxiliary `b^4 c` comparison still needs its own corrected replay.
