# Source-complete product forests in four dimensions

The product-forest evaluator now retains arbitrary conserved rational
sources on every surviving vertex. It integrates source-free local stars,
preserves exact current brackets, and evaluates the remaining complete
current polynomial against a sourced core. A missing finite period is
represented by a **complete convergent rational series with an explicit
remainder bound**. This supplies an exact computational route for every
valid product forest and every finite original-edge current word, subject
to explicit allocation budgets.

Finite zeta formulas for every forest, and inexpensive evaluation at
arbitrary size, are separate goals. A returned series object contains the
full series specification; its finite partial sums are accompanied by
rigorous rational errors and are never substituted for the exact answer.

## The computational improvement

The manuscript's source-free star identities require zero source only at
the removed centres. A retained parent may have higher valence and a
nonzero source. The new planner uses exactly those hypotheses and
integrates the two or four local ratios immediately. Original edge order,
edge orientation, current insertions, and all retained sources are kept.
The resulting graph need not be series-parallel or source-free.

Before substituting core currents, the evaluator factors their complete
polynomial. For the repository's Kirchhoff polynomial `U`, every
antisymmetric bracket has only **one** denominator:

\[
U\langle y_e,y_f\rangle
\quad\text{is a homogeneous polynomial in the resistances.}
\]

Its bordered-determinant proof is in [DERIVATION.md](DERIVATION.md).
Exact polynomial division removes the extra factor of `U` before powers
are expanded. Passive elimination consequently preserves the original
denominator level. In the series-parallel route, the same factor-first
strategy keeps ratio factors separate for exact simplex integration.

The residual density comes from the repository's existing exact linear
current-minor determinant. The implementation integrates series chains,
groups graph symmetries, and queries existing finite period tables in a
private read-only worker. Unsupported finite periods use the existing
Hepp-series recurrence. No interpolation, fitted constants, or numerical
stabilization criterion enters these results.

| Route | Result |
|---|---|
| Cubic root-source forests | Existing three-boundary-current recursion |
| Generic series-parallel forests | Exact rational integration with every source retained |
| Allowed passive stars | Exact smaller sourced graph with a finite current polynomial |
| Available core periods | Rational number or finite rational combination of stored zeta products |
| Unavailable finite periods | Full exact convergent series with rational tail bounds |

## Complete finite calculations

All values use **htk's kernel convention**, with original ordered edges
and orientations. They are raw current moments, before displacement
signs and factorials. Full graphs, sources, words, and exact coefficient
dictionaries are in [certificate.json](certificate.json), generated by
[certify.py](certify.py). [fixtures.py](fixtures.py) constructs each input.

### Irreducible physical quartic forest at five loops

The ordered edges are

\[
(01,13,02,24,05,06,35,36,45,46,56).
\]

The marked pair is `(5,6)`. The conserved source assignment is

\[
((0,0),(1,2),(3,-1),(0,0),(0,0),(5,3),(-9,-4)).
\]

The quartic vertex has zero source, and neither passive star identity
applies. Complete integration gives

\[
\boxed{
\frac{3327759589}{46656000}
+\frac{50942017}{324000}\zeta(3)
-\frac{45619}{180}\zeta(5).
}
\]

The exact determinant has 91,473 monomials. Integrating the two series
chains and grouping symmetries leaves 2,474 nonzero period orbits.
[independent_duality.py](independent_duality.py) independently constructs
the planar face dual, verifies the full Kirchhoff inversion identity,
and contracts the triangular-prism table directly. Rational integral-test
bounds also certify that the complete kernel lies strictly between
`-3` and `-2`; its nonvanishing does not assume algebraic independence
of zeta values.

## Public interface

From the repository root:

```python
import sys
sys.path.insert(0, "code")
from htk import Graph, ProductForestMoments

graph = Graph(7, [
    (0, 1), (1, 3), (0, 2), (2, 4), (0, 5), (0, 6),
    (3, 5), (3, 6), (4, 5), (4, 6), (5, 6),
])
sources = [
    (0, 0), (1, 2), (3, -1), (0, 0), (0, 0), (5, 3), (-9, -4),
]

with ProductForestMoments(
    graph, sources, marked=(5, 6), max_terms=1_000_000
) as forest:
    value = forest.moment()
    print(value.as_sympy())
    print(forest.last_stats)
```

`moment(powers)` accepts the original-edge dictionary
`{(edge_index, current_coordinate): nonnegative_integer_power}`. Inputs
use exact rational arithmetic. The return types are:

- `fractions.Fraction` for a rational answer.
- `ExactPeriod` for a finite expression. Its immutable `.coefficients`
  contains rational coefficients of labels such as `1`, `z3`, and `z5`;
  `.as_sympy()` gives the corresponding symbolic expression. Equality
  compares these expressions and assumes no unproved transcendence result.
- `ExactForestSeries` for a complete series. `.terms(last)` yields each
  exact rational term, partial sum, and absolute tail bound through that
  order. `.interval(last)` returns rigorous rational lower and upper
  bounds. `.reason` records the unavailable finite reduction.

`forest.series(powers)` explicitly selects the convergent-series route
for a sourced core. Existing cubic and series-parallel rational routes
return their exact value as a terminating series. `allow_series=False`
requires a finite result and raises `UnsupportedProductForestReduction`
if its period is unavailable. Resource errors remain explicit exceptions.

The default core checks compare its exact numerator against the original
current-Jacobian density at two rational points. `max_terms`,
`max_tree_candidates`, `max_period_terms`, `max_matrix_entries`,
`max_series_edges`, and `period_timeout` expose the main resource limits;
`max_states` controls the cubic recursion. The old direct series-parallel
integrator retains its own allocation behavior. A context manager releases
the private period worker; `.close()` is also available.

## What remains

This resolves the former blanket rejection of sourced non-series-parallel
product forests. The universally available result is an exact convergent
series at rational sources and any finite current order; it is not a
universal finite zeta classification. The subset recursion can require
exponentially many states, and polynomial size and rational bit lengths
grow. Further work is to enlarge finite core reductions and exploit
boundary structure before that recursion becomes expensive. The present
implementation concerns four real dimensions, `H=2,T=0`.

The underlying source-free star theorems, current-minor determinant,
finite period tables, and Hepp-series algorithm predate this contribution.
The new work connects them through a source-preserving contraction planner,
exact bracket cancellation, a public forest interface, and independently
replayable higher-loop calculations.
